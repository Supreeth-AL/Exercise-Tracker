# Exercise Tracker

A simple, user-friendly full-stack JavaScript app for logging physical exercise. Users can create an account, add exercises (description, duration, date), and retrieve a history of workouts with optional date range and limit filters. This project demonstrates building RESTful APIs, persistent storage with MongoDB, and a responsive frontend written in JavaScript.

# Key features
  1.Create a new user profile (username)
  2.Add an exercise entry for a user: description, duration (minutes), optional date
  3.Retrieve a user’s exercise log
  4.Optional from / to date filters
  5.Optional limit to cap number of results
  6.Simple, clean frontend to interact with the API
  7.JSON responses for API endpoints (suitable for programmatic use)
  8.Validation and helpful error messages

# Tech stack
  1.Backend: Node.js, Express
  2.Database: MongoDB (Mongoose)
  3.Frontend:JavaScript/HTML/CSS
  4.Environment: npm, dotenv for config 
  5.Dev tools: VS Code, Postman  for testing
